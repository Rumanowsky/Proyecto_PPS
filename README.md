# Proyecto Web ASIR - Lista de Productos (PHP Síncrono + API)

Aplicación sencilla hecha en PHP con SQLite, estructura Modelo-Vista-Controlador, sin AJAX/fetch en el navegador (formularios HTML tradicionales) y manteniendo las rutas JSON de la API común.

## Cómo arrancar el servidor
Ejecuta este comando en la terminal dentro de la carpeta del proyecto:
```bash
php -S 0.0.0.0:8080 -t public
```
Luego abre en el navegador: `http://localhost:8080`
